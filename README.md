# Cloud Cost Optimization Platform

A Java/Spring Boot platform that helps engineering teams understand AWS spending:
it ingests cost data (AWS Cost Explorer or a documented CSV format), breaks it
down by service and environment, tracks budgets, flags unusual cost increases
with explainable rules, and produces evidence-based optimization recommendations.

> Status: under active development. Full documentation will be added as the
> implementation lands.
