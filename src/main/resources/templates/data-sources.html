Each synchronization replaces previously synchronized records in the range, because Cost Explorer revises recent (estimated) figures. AWS bills every paginated Cost Explorer API request (currently USD 0.01 per request); ranges are limited to 90 days.

The integration is optional and disabled. To enable it, set COSTPLATFORM_AWS_ENABLED=true and make credentials with the ce:GetCostAndUsage permission available through the AWS SDK default credential provider chain (for example an IAM role). CSV imports work without AWS access.
