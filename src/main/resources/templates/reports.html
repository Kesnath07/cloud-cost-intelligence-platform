File formats

Summary CSV: one table with the columns section, name, value, comparison_value, change, change_percent, percent, status, date, notes. The section column identifies report metadata, the period total, each service, each environment, budgets (value = spend, comparison_value = limit, percent = utilization), anomaly findings (value = observed, comparison_value = baseline) and recommendations (value = estimated monthly savings, empty when not estimated). Amounts use the reporting currency with two decimals; percentages are empty where undefined.

Daily costs CSV: date, service, environment, amount, currency, one row per day, service and environment with stored cost.

Text that a spreadsheet could execute as a formula is prefixed with an apostrophe.
